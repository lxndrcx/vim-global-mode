1. INTRODUCTION                                   *global-mode-introduction*

There is one mode, and everybody is in it. Connect to a global mode server and
your modal state is no longer yours: when anyone connected presses `i`, every
editor on that server enters insert mode.

This is a joke plugin. It works exactly as described.

Requires Neovim 0.10 or newer. Pure Lua, no dependencies.

==============================================================================
2. SETUP                                                 *global-mode-setup*

>lua
    require("global-mode").setup({
      host = "127.0.0.1",
      port = 7777,
      user = vim.env.USER,
    })
<
The server is a separate project, written in Ada and verified with SPARK:

    https://github.com/lxndrcx/vim-global-mode-server-ada

Build and run it with: >

    git clone https://github.com/lxndrcx/vim-global-mode-server-ada
    cd vim-global-mode-server-ada
    gprbuild -P global_mode.gpr
    ./bin/global_mode --verbose
<
Nothing in this plugin needs an Ada toolchain; it speaks to whatever server is
listening on the configured port. Transport is UDP, in fixed 84-byte frames.

==============================================================================
3. CONFIGURATION                                        *global-mode-config*

                                                    *global-mode-setup-opts*
host                    string (default "127.0.0.1")
                        Address of the global mode server. Must be a numeric
                        address: libuv does not resolve hostnames, so
                        "localhost" fails to connect and retries forever.

port                    number (default 7777)
                        UDP port the server listens on for editors.

user                    string (default $USER, then $USERNAME, then "anon")
                        The name shown to everyone else when you change the
                        mode. This is who gets blamed. It travels in a fixed
                        32-byte field: a longer name is truncated to 32 bytes
                        rather than refused, and the truncation is by byte, so
                        a multi-byte character can be cut in half.

auto_connect            boolean (default true)
                        Connect on startup. Set false to require an explicit
                        |:GlobalModeConnect|.

notify                  boolean (default true)
                        Announce connection and disconnection with
                        |vim.notify()|.

reconnect               table (default { min = 1000, max = 30000 })
                        Exponential backoff bounds in milliseconds, governing
                        how often the handshake is retried while offline. The
                        delay doubles from `min` on each unanswered attempt,
                        capped at `max`. It does not apply once online: there
                        the server's own refresh is the liveness signal, and a
                        long backoff would make one lost datagram look like a
                        dead server.

==============================================================================
4. COMMANDS                                           *global-mode-commands*

                                                       *:GlobalModeConnect*
:GlobalModeConnect      Connect to the server and submit to the global mode.

                                                    *:GlobalModeDisconnect*
:GlobalModeDisconnect   Disconnect and reclaim your own modal state.

                                                        *:GlobalModeStatus*
:GlobalModeStatus       Report the global mode, who set it, and how many other
                        editors are connected. The count is whatever the last
                        roster said, which is none until something asks for
                        one -- see |global-mode-roster|.

:checkhealth global-mode
                        Report connection state, the global mode, and the
                        roster of connected editors. This is the only thing
                        that requests a roster, so it is also what makes
                        |global-mode.others()| non-empty.

5. STATUSLINE                                       *global-mode-statusline*

For lualine: >lua
    sections = { lualine_x = { require("global-mode").lualine() } }
<
Or build your own from the pieces: >lua
    require("global-mode").statusline()  -- "INSERT · alex"
    require("global-mode").highlight()   -- "GlobalModeInsert"
<
                                                  *GlobalModeChanged*
A |User| autocmd fires on every change, so other statusline plugins can hook
redraws: >lua
    vim.api.nvim_create_autocmd("User", {
      pattern = "GlobalModeChanged",
      callback = function() ... end,
    })
<
                                                  *global-mode-highlights*
These highlight groups are defined, each linked to a sensible default:

    GlobalModeNormal        GlobalModeInsert        GlobalModeVisual
    GlobalModeReplace       GlobalModeCommand       GlobalModeTerminal

6. API                                                     *global-mode-api*

global-mode.setup({opts})                            *global-mode.setup()*
                Configure and, unless disabled, connect.

global-mode.connect()                              *global-mode.connect()*
global-mode.disconnect()                        *global-mode.disconnect()*
global-mode.is_connected()                    *global-mode.is_connected()*
                True once connected *and* welcomed by the server, meaning the
                global mode is actually known.

global-mode.mode()                                    *global-mode.mode()*
                The global mode as a single character (`n`, `i`, `v`, `V`, `b`,
                `R`, `c`, `t`), or nil when offline. It is cleared whenever the
                connection drops, not only on |:GlobalModeDisconnect|.

global-mode.statusline()                        *global-mode.statusline()*
global-mode.highlight()                          *global-mode.highlight()*
global-mode.lualine()                              *global-mode.lualine()*
global-mode.status()                                *global-mode.status()*
global-mode.others()                                *global-mode.others()*
                Everyone connected except you, from the last roster received.
                Empty until one is requested; |:checkhealth| is what requests
                it. See |global-mode-roster|.

global-mode.state                                        *global-mode.state*
                Table with `mode`, `by`, `seq`, `id`, `peers` and `status`.
                `id` is the small integer the server seated you at, `seq` its
                change counter, and `status` one of "offline", "connecting"
                or "online".

==============================================================================
7. HOW IT WORKS                                      *global-mode-internals*

A |ModeChanged| autocmd reports your mode to the server, which records it as
the global mode and pushes it to every other editor. Those apply it with
|nvim_feedkeys()|, always prefixed with CTRL-\ CTRL-N — the one escape that
works from every mode, terminal mode included.

Three things stop one keypress becoming an infinite storm:

  1. The server never echoes a change back to whoever caused it.
  2. The client stays quiet about the |ModeChanged| events its own forced
     change produces. Note the plural: because every applied mode is fed as
     CTRL-\ CTRL-N followed by a mode key, applying one from a different
     non-normal mode passes through normal and fires two events, not one. The
     client therefore tracks a queue of expected modes, treats a transit
     through normal as its own, and expires an entry after half a second in
     case the keys never take effect.
  3. Re-reporting the mode already in force is a no-op on the server, and does
     not advance the sequence counter.

Reports are also coalesced: a change is held for 20 milliseconds, so a burst
becomes one datagram carrying the mode you ended on. Each report carries a
counter, and the server ignores any report that is not newer than the last it
honoured from that editor — without it, two reports sent a millisecond apart
and reordered in flight would leave everybody in the mode you had just left.
The counter restarts on every handshake, on both sides at once.

                                                        *global-mode-frames*
Transport is UDP, in frames of exactly 84 bytes. One datagram is one frame, so
the plugin does no framing: there is no length prefix to read, no delimiter to
scan for and no half-a-message to hold onto. The frames are packed by hand,
because the LuaJIT Neovim ships has no `string.pack`.

                                                     *global-mode-handshake*
Joining takes a round trip. A UDP source address is forgeable, so the server
answers your hello with a token computed from the address that hello arrived
from, and seats you only when you echo it back. The token is computed rather
than stored, so a flood of hellos has no table to exhaust. The client echoes it
untouched and never looks inside.

The client also ignores every datagram that did not come from the configured
host and port. Its socket is bound to a wildcard port that any local process
can reach, and one forged frame is otherwise enough to drag this editor into a
mode nobody chose. That stops strays and unprivileged local processes, not an
attacker who can forge the source address as well.

                                                       *global-mode-resync*
There is no resync, because nothing is ever incremental. The server does not
announce that the mode changed; every frame it sends carries the whole state —
the mode, who set it, and which change number it is — and the client adopts
anything newer than what it holds. Order does not matter, duplicates are
no-ops, and a datagram lost in flight is replaced by the refresh a couple of
seconds later. An earlier version of this protocol announced only changes, and
every way of missing one was permanent.

That is only true of frames coming from the server, which carry state. Mode
reports going the other way are events, and are ordered by the counter above.

                                                     *global-mode-liveness*
The same refresh is the liveness probe. Some refreshes ask for a pong; three
unanswered ones — about six seconds — and the server frees your seat. The
client watches the same clock from its side: six seconds with nothing from the
server and it declares the server gone, clears the global mode, and starts the
handshake again on the |global-mode-config| backoff. Both ends therefore give
up at about the same moment, rather than one of them talking to nobody.

|:GlobalModeDisconnect| does not rely on that: it says goodbye explicitly, so
the seat is freed at once.

                                                       *global-mode-roster*
The roster is pull-only. Broadcasting one on every join and departure was an
O(n) amplifier on the server, so it is sent one frame per editor in reply to a
request, and `:checkhealth global-mode` is the only thing in this plugin that
asks. Entries are collected by index until the set is whole, so a duplicated or
reordered datagram cannot publish a roster with somebody listed twice and
somebody else missing.

                                                   *global-mode-operator-pending*
Operator-pending mode is dropped before anything is scheduled. A |ModeChanged|
autocmd calling |vim.schedule()| could once re-trigger itself in a loop between
normal and operator-pending until it saturated a core (neovim issue #22263).
So pressing `d` or `y` does not affect anyone else: you can still operate on
text, you simply cannot inflict a half-finished operator on the room.

Terminal mode is received and displayed but never forced.

A circuit breaker caps applied changes at 20 per second. If it trips, a warning
is issued and applies pause briefly, so a bug degrades into a log line rather
than a hung editor.

                                                       *global-mode-security*
There is no authentication. The handshake |global-mode-handshake| proves only
that you can receive at the address you claimed; it says nothing about who you
are, and the name you report is whatever you care to type. Anyone who can
reach the port can join and change the mode for everyone connected. Do not
expose it to the public internet.
